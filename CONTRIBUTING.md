# Contributing

Thanks for helping make coding agents more deliberate.

## What belongs here

- A concise rule that prevents a demonstrated scope, verification, or stopping failure.
- A clearer trigger or instruction that improves behavior across multiple agent hosts.
- A compatibility fix for the portable Agent Skills format.
- A realistic before/after example that exposes a gap.

## What does not belong here

- General coding style advice.
- Model-bashing or unsupported claims about a provider.
- Copies of private, leaked, or proprietary prompts.
- Mandatory process that costs more than the failure it prevents.
- Executable tooling when a short instruction is sufficient.

## Pull requests

Keep each pull request focused. Explain the observed failure, the smallest proposed rule, and how you evaluated the behavior. Changes should preserve the skill's central contract:

> Smallest sufficient change. Proportionate proof. Then stop.
